# MUSAFIRUN APP

Projecte intermodular DAM2 (2025/2026) de **Basmala Azouagh el Addouti**.

## Descripció
Musafirun és una aplicació Android orientada a viatgers per centralitzar organització de viatges, consulta de notícies, buscador de països, minijocs i configuració de perfil.

## Funcionalitats principals
- Organització de viatges (llistes, reserves, gastos, llocs, fotos)
- Pantalla principal amb notícies i contingut rellevant per viatgers
- Buscador de països amb fitxa detallada
- Minijocs (banderes, capitals, cultura general)
- Ajustos de perfil, idioma i tema
- Base per funcionalitats premium (guardades/compartides/favorites)

## Tecnologies
- Kotlin
- Android (Fragments, RecyclerView, Material Components)
- Firebase (Auth / Firestore / Storage)
